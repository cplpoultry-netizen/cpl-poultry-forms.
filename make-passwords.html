Make new passwords

Type the 3 passwords you want. Press the button. It downloads a small file called passwords.js. Upload that file to your GitHub repo (replace the old one). Everyone will be asked to log in again with the new passwords.

If the download did not work, press Copy the text. On GitHub open passwords.js, tap the pencil (edit), select everything, paste, then press Commit changes.
